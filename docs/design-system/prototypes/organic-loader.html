EdForge — Organic loader: "The Forge"

A living crucible that breathes while the EdForge mark forges itself. Real mark path · real tokens · no spinners.

The current loader is an inline letter "E" in a green box with three bouncing dots. This replaces it with one organic system used everywhere: a soft squircle "crucible" that breathes and morphs its corners while the actual EdForge mark (from logo.svg) draws itself, finished by an ember sheen that sweeps the forged stroke. One component, four states, two color stories. Toggle dark mode above; enable "reduce motion" in your OS to see the calm fallback.

Setting up your workspace…
State: BOOT (full-screen)
App cold-start & the one-time school resolve. Replaces LoadingScreen. The mark forges once, holds, breathes — feels alive, not "stuck".
Loading Academics…
State: MODULE (MFE chunk load)
Suspense fallback for a federated remote. Crucible takes the module accent (academics blue / finance red / people coral) so the wait is wayfinding, not dead time.
Switching to Saraswati Secondary
State: SCHOOL-SWITCH (overlay)
Only on a deliberate user switch — never on first paint. Names the destination school so the user knows exactly what's happening. Replaces the bare "Switching school…" dots.
Color story B — "Forge ember"
Variant: EMBER (app palette)
Molten green → amber that shifts like hot metal — uses the operator app's accent (#0F6E56 / #EF9F27). Story A (left tiles) uses the literal logo gradient (#005f73 → #0a9396). Pick one — see the brand-color note in the plan.
Inline · 40px and 22px
State: INLINE (small)
Replaces the border-spinner in LoadingState and in buttons. Just the breathing crucible — no text, no draw — calm and tiny.
Reduced-motion fallback
No morph / draw / sheen — fully-formed mark with a gentle opacity breathe. Honors prefers-reduced-motion (a stated design principle).
Accessibility
Every state degrades to this. Motion is opt-in by OS preference; the brand still reads.
